# Vikrant Nayak — Portfolio Website

A responsive, clean and professional portfolio website for Vikrant Nayak, an AI/ML engineering graduate interested in Python development, machine learning, and computer vision. Built with HTML, CSS, and vanilla JavaScript; no build step is required.

- [Sign Language Recognition System](https://github.com/Vikrantnayak/Sign-Language-Recognition-System)
- [Driver Fatigue Prediction System](https://github.com/Vikrantnayak/Driver-Fatigue-Prediction-System)
- [AI-Driven Personalized Investment & Financial Advisor](https://github.com/Vikrantnayak/AI-Financial-Advisor)

Project cards link to GitHub repositories only; no project live-demo URLs are included.

## Run locally

Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Deploy to Vercel

1. Import this GitHub repository in Vercel.
2. Choose the framework preset **Other**.
3. Leave the build command empty.
4. Leave the output directory blank/default and deploy.

This is a static website and requires no server-side environment variables.
